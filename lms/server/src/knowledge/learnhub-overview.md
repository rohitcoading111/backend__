
# LearnHub – Company Overview

## Company Identity

Company Name: LearnHub
Official Website: https://learnhubcloud.in

LearnHub is an online Learning Management System (LMS).

The platform provides a digital environment for managing
courses, instructors, students and online learning activities.

## Platform User Roles

LearnHub supports the following user roles:

1. SUPER_ADMIN
2. ORGANIZATION_ADMIN
3. INSTRUCTOR
4. STUDENT

## Core Platform Features

### 1. Course Management
- Instructors can create courses.
- Courses contain modules and lectures.
- Courses can be published and unpublished.
- Courses have descriptions, thumbnails, categories and pricing.

### 2. Student Learning
- Students can register and log in.
- Students can enroll in courses.
- Students can access their enrolled courses.
- Students can track lecture completion and learning progress.

### 3. Live Classes
- LearnHub supports live learning sessions.
- LiveKit is used for live class infrastructure.
- Instructors can manage live sessions.
- Students can join active sessions.

### 4. Organization Management
- Organizations have dedicated administration.
- Organization administrators manage their organization.
- Instructors can be assigned to organizations.
- Organization-level access control is implemented.

### 5. Learning Progress
- Lecture completion is tracked.
- Student learning progress is maintained.
- Course progress can be displayed on dashboards.

### 6. Authentication and Security
- JWT-based authentication.
- Access and refresh token architecture.
- Role-based authorization.
- Password hashing using bcrypt.

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Integrations
- LiveKit: Live classes
- ImageKit: Media management
- Razorpay: Payment integration (planned/in progress)
